AnyTTY Third-Party Notices

本文件是当前仓库的第三方材料索引。根 LICENSE 对 AnyTTY 自有材料的当前约定不改变任何第三方材料的原始许可。

Artifact Notice Bundles

- anytty CLI/daemon: cmd/anytty/THIRD_PARTY_NOTICES.txt; 用户入口为 anytty licenses。
- Web client: clients/web/public/THIRD_PARTY_NOTICES.txt 和 clients/web/public/third-party/; 随 daemon 的 Local Web bundle 分发。
- Flutter clients: clients/flutter/assets/licenses/; 随 Android 与 iOS 应用分发。

这些 bundle 按实际 Go build graph、npm lockfile、Gradle runtime graph 和内嵌资产分别生成。单独列出 SPDX 名称或本索引不能替代 artifact 内的完整版权、许可和 NOTICE 文本。

Vendored And Embedded Material

- vterm/internal/vt/LICENSE: Charmbracelet terminal implementation 的 MIT 文本。
- clients/ui/src/assets/fonts/LICENSE: 当前 App 内嵌 Nerd Font Mono 字体的 attribution 与 OFL-1.1 文本。
- clients/web/public/third-party/NPM_NOTICES.txt: Web 生产依赖清单，包括 Apache-2.0 的 file-viewer React 组件及 text/PDF/Word/spreadsheet/media/3D 渲染器；其中 3D 运行时使用的 occt-import-js 及其 Open CASCADE WebAssembly 组件按 LGPL-2.1 分发，完整许可证与上游说明一并收录。
- third_party/ghostty/LICENSE: Flutter 终端输入与解析层使用的 libghostty-vt 许可文本。
- docs/legal/third-party/: npm/Maven artifact 没有随包提供独立 license 文件时使用的固定上游文本。

Reproducible Audit

旧 license audit 与 public snapshot 文档门禁已随 Cloud 旧代码删除。选择并落地开源许可证后，必须建立与单一开源仓库匹配的新 audit，并在发布时同时生成 SBOM、签名和 provenance。
