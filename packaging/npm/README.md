# @anytty/cli

Installs the platform-specific AnyTTY binary from the matching GitHub Release and verifies it against the published `SHA256SUMS` file.

```sh
npm install --global @anytty/cli
anytty --version
```

Supported targets are macOS, Linux, and Windows on x64 or ARM64. AnyTTY is currently beta software; see the [main repository](https://github.com/anytty/anytty) for documentation and source.
