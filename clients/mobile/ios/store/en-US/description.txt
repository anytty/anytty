AnyTTY is an open-source terminal and file client for computers you own or are authorized to access.

Pair the app with an AnyTTY daemon, then open persistent terminal sessions and work with files from your iPhone or iPad. Use a local network, an SSH route, a direct peer-to-peer connection, or optional AnyTTY Cloud connectivity when the computer is behind NAT.

Features:

- Open and switch between persistent terminal sessions
- Use touch-friendly keys for Esc, Ctrl, arrows, paging, and common terminal actions
- Browse, upload, download, and preview files
- Pair explicitly by QR code or a pasteable pairing command
- Discover paired computers on the local network
- Use encrypted SSH, Direct, and Cloud routes
- Revoke a paired client's access from the endpoint daemon

The AnyTTY app does not require an account. Local, SSH, and Direct routes do not require an AnyTTY Cloud subscription. An optional Cloud service can help paired devices discover each other, negotiate a direct connection, and relay encrypted traffic when a direct path is unavailable.

Terminal and file permissions remain under the control of the endpoint daemon. Use AnyTTY only with systems and data you own or are authorized to access.
