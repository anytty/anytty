AnyTTY 是一款开源终端与文件客户端，用于连接你拥有或已获授权访问的电脑。

将 App 与 AnyTTY daemon 配对后，即可从 iPhone 或 iPad 打开持久终端并处理文件。你可以使用局域网、SSH、点对点直连，也可以在电脑位于 NAT 或内网后方时选择 AnyTTY Cloud 连接。

主要功能：

- 打开并切换持久终端会话
- 使用适合触控的 Esc、Ctrl、方向键、翻页键和常用终端操作
- 浏览、上传、下载和预览文件
- 通过二维码或可粘贴的配对命令明确授权客户端
- 在局域网中发现已配对电脑
- 使用加密的 SSH、Direct 和 Cloud 路由
- 从 endpoint daemon 撤销已配对客户端的访问权限

AnyTTY App 无需注册账号。Local、SSH 和 Direct 路由不需要 AnyTTY Cloud 订阅。可选 Cloud 服务可以帮助已配对设备发现对方、协商直连，并在无法直连时转发加密流量。

终端与文件权限始终由 endpoint daemon 控制。请仅使用 AnyTTY 访问你拥有或已获授权使用的系统和数据。
