# App Store product-page copy

These files contain public, non-secret copy for the AnyTTY iOS product page.
Paste the matching localization into App Store Connect and compare it with the
submitted build before every release.

Fields that identify the account holder, review contact, distribution regions,
copyright owner, and review pairing environment are intentionally excluded. Enter
those directly in App Store Connect. Never commit reviewer credentials, pairing
claims, private hosts, Apple certificates, or API keys here.

Use these URLs for the first release:

- Privacy Policy URL: `https://anytty.com/privacy/`
- Support URL: `https://anytty.com/support/`
- Marketing URL: `https://anytty.com/`

The app is free, accountless, and contains no purchase or external-checkout call to
action. Reassess the copy and Apple's payment rules before adding an upgrade link,
account login, subscription state, or purchase flow to the app.
