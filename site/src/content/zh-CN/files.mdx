# 文件管理

文件访问通过选定的 endpoint route 传输，但它始终是 daemon 单独授予的 capability。

## CLI 入口

```sh
anytty file --help
anytty file roots
anytty file list <root-and-path>
```

当前 CLI 提供列表、上传、下载、取消和传输检查命令。首次发布前语法仍可能变化，请以命令帮助为准。

## 安全属性

- 请求只能解析到 daemon 配置的文件根目录中。
- 终端权限不隐含文件权限。
- 传输支持取消与完整性校验。
- 移动端凭据保存在原生保护存储，而不是 WebView storage。

> **不要随意暴露宽泛根目录。** 只授予完成工作所需的最小根目录与 capability。下载的终端产物和日志应按敏感用户数据处理。
