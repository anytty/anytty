# 文件管理

文件访问使用与终端相同的连接，但它是 daemon 单独授予的权限。

## CLI 入口

```sh
anytty file --help
anytty file roots
anytty file list <root-and-path>
```

当前 CLI 提供列表、上传、下载、取消和传输检查命令。首次发布前语法仍可能变化，请以命令帮助为准。

## 安全属性

- 请求只能解析到 daemon 配置的文件根目录中。
- 有终端访问权限不代表自动有文件访问权限。
- 传输支持取消与完整性校验。
- 移动端凭据保存在原生保护存储，而不是 WebView storage。

> **保持文件根目录尽量窄。** 只授予完成工作所需的最小根目录与权限。下载的终端产物和日志应按敏感用户数据处理。
