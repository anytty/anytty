# 快速开始

从当前源码构建，启动当前用户的 daemon，然后进入 TUI。AnyTTY 尚未发布，本文跟随仓库当前状态，而不是某个稳定安装包。

## 环境

安装 Go 1.26.5、Node.js 24 和 npm，然后克隆公开仓库并安装 lockfile 固定的依赖。

```sh
git clone https://github.com/lozzo/anytty.git
cd anytty
npm ci
make build
```

二进制输出到 `.artifacts/bin/anytty`。

## 本地运行

```sh
./.artifacts/bin/anytty daemon start
./.artifacts/bin/anytty
```

第二条命令针对默认 Local endpoint 打开 TUI。也可以直接从 CLI 创建 shell 并附加：

```sh
./.artifacts/bin/anytty terminal create --attach -- zsh
```

## 验证 checkout

```sh
make test
make test-clients
npm run public:check
```

> **需要连接其他机器？** 已有主机访问能力时优先使用 SSH；也可以配对支持 Direct 或 Cloud 的服务并保存为 endpoint。
