# 安全模型

daemon 拥有保护终端与文件的身份和授权决定。传输或托管策略可以拒绝可达性，但不能提升客户端从 daemon 获得的 capability。

## 安全不变量

- pairing claim 与 enrollment 材料短期、一次性并拒绝重放。
- capability grant 绑定客户端身份并由 daemon 执行。
- Cloud AgentGateway 与 ClientGateway 使用 challenge-first proof 认证。
- Cloud policy 缺失或不一致时 fail closed。
- 终端与文件内容不属于 Controller 的权限范围。
