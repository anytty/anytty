# AnyTTY Cloud

AnyTTY Cloud 是一项可选的托管连接服务，适合难以直接访问的终端，并可直接配合开源的 AnyTTY 客户端与 daemon 使用。

[查看 Cloud 套餐与公开价格](/zh-CN/cloud/#pricing)，或[创建 Cloud 账号](https://cloud.anytty.com/register)。

## Cloud 额外提供

- 托管设备发现
- 网络条件允许时自动协商 P2P 连接
- 无法直连时使用 Relay 兜底
- Web 端与移动端一致的连接体验

## 安全边界

Cloud 帮助已经获得授权的客户端到达目标 daemon。终端与文件权限仍由 daemon 决定，远程流量经过身份验证和加密；Relay 只转发加密流量，不会获得终端或文件访问权限。

如果希望自行管理网络连接，仍可继续使用 Local、SSH 和 Direct 连接。完整的用户信任模型见[安全边界](https://github.com/anytty/anytty/blob/main/docs/zh-CN/SECURITY_BOUNDARY.md)。
