# Quick start

Install the current beta, start the daemon for your user, and open the TUI. From there you can create terminals, attach to them later, and manage them from the CLI or mobile app.

## Install

On macOS or Linux, the installer downloads the matching release archive and verifies its SHA-256 checksum:

```sh
curl -fsSL https://raw.githubusercontent.com/anytty/anytty/main/install.sh | sh
```

On Windows PowerShell:

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/anytty/anytty/main/install.ps1 -OutFile install.ps1
.\install.ps1
```

## Run locally

```sh
anytty daemon start
anytty
```

The second command opens the TUI and connects to the local daemon. To create a shell and attach directly from the CLI:

```sh
anytty terminal create --name workspace --attach -- zsh
```

To use the same daemon from a Web browser:

```sh
anytty web
```

The Web interface listens only on your machine's IPv4 loopback address. Run `anytty web --no-open` to print its URL, `anytty web status` to inspect it, or `anytty web stop` to close the browser entry point without stopping terminals.

### Password-protected Web access

Add a password before publishing Local Web through a reverse proxy or tunnel:

```sh
anytty web --password --no-open
```

AnyTTY reads and confirms a passphrase of at least 12 characters directly from the terminal. It does not place the password in shell history, command-line arguments, or `web status` output. Stop and restart Local Web to change the password.

Keep the AnyTTY listener on loopback and terminate TLS at a reverse proxy or tunnel on the same machine. The public endpoint must:

- use HTTPS;
- proxy the printed Local Web URL at the origin root;
- forward WebSocket upgrades for `/api/bridge` as well as normal HTTP requests;
- preserve the public `Host`, or send it as `X-Forwarded-Host`; and
- send `X-Forwarded-Proto: https` when TLS terminates at the proxy.

The browser receives a non-persistent, `HttpOnly`, same-site session cookie after login. Anyone who knows the password has the same terminal and file permissions as the local AnyTTY Web interface, so use a unique passphrase and keep login throttling enabled at the proxy as an additional layer.

## Build from source

Source builds require Go 1.26.7, Node.js 24, and npm.

```sh
git clone https://github.com/anytty/anytty.git
cd anytty
npm ci
make build
make test
make test-clients
npm run public:check
```

> **Want to work on another machine?** Use SSH when you already have host access, or pair a Direct/Cloud-capable service and save it as an endpoint.
