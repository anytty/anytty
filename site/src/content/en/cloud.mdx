# AnyTTY Cloud

AnyTTY Cloud is an optional managed connection service for terminals that are difficult to reach directly. It works with the open-source AnyTTY clients and daemon.

## What Cloud adds

- Managed device discovery
- P2P connection negotiation when the network allows it
- Relay fallback when a direct path is unavailable
- One connection experience across desktop and mobile clients

## Security boundary

Cloud helps an authorized client reach the target daemon. The daemon still decides terminal and file permissions, and remote traffic is authenticated and encrypted. A Relay forwards encrypted traffic without gaining terminal or file access.

Local, SSH, and Direct connections remain available when you prefer to manage reachability yourself. See the [security boundary](https://github.com/anytty/anytty/blob/main/docs/SECURITY_BOUNDARY.md) for the complete user-visible trust model.
