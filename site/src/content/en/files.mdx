# File management

File access uses the same connection as your terminal, but it is a separate permission granted by the daemon.

## CLI discovery

```sh
anytty file --help
anytty file roots
anytty file list <root-and-path>
```

The current CLI exposes listing, upload, download, cancellation, and transfer inspection commands. Consult command help because syntax may change before the first release.

## Safety properties

- Requests are resolved within daemon-configured file roots.
- Having terminal access does not automatically give file access.
- Transfers support cancellation and integrity checks.
- Mobile credentials remain in native protected storage rather than WebView storage.

> **Keep file roots narrow.** Only grant the smallest root and permission needed for the work. Treat downloaded terminal artifacts and logs as potentially sensitive user data.
