# Terminal management

A terminal stays alive under the daemon while clients attach, detach, reconnect, or switch between live output and saved history. Closing a client doesn't stop the terminal.

## Core lifecycle

```sh
anytty terminal create --attach -- zsh
anytty terminal list
anytty terminal attach <terminal-id>
anytty terminal show <terminal-id>
anytty terminal kill <terminal-id>
anytty terminal remove <terminal-id>
```

Run `anytty terminal --help` for the exact flags in the current checkout. Killing stops the process; removing deletes an exited terminal record.

## Live and history

Live rendering and history use separate cursors. You can freeze a history viewport while new output continues, then return to the current live frame without making the terminal process wait for you.

> **Bounded by design.** Per-terminal output and subscriber queues have byte budgets. Slow or disconnected clients won't make the daemon grow without limit.
