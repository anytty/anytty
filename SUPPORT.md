# Support

AnyTTY is pre-release software. There are currently no supported releases, service-level commitments, paid support plans, or guaranteed response times.

## Where to ask

- Use [GitHub Discussions](https://github.com/anytty/anytty/discussions) for setup questions, design discussion, and usage help once Discussions is enabled.
- Use the [bug report form](https://github.com/anytty/anytty/issues/new?template=bug_report.yml) for reproducible defects in public source.
- Use the [feature request form](https://github.com/anytty/anytty/issues/new?template=feature_request.yml) for scoped proposals.
- Use [private vulnerability reporting](https://github.com/anytty/anytty/security/advisories/new) for security issues. Never post exploit details or credentials publicly.

Before filing, search existing issues and run the checks documented in `CONTRIBUTING.md`. Include the operating system, commit, route type, exact command, observed behavior, and sanitized logs. Do not include pairing claims, capability grants, keys, terminal contents, personal data, or production service identifiers.

Managed AnyTTY Cloud availability, account support, and commercial terms are separate from community support for this source repository. Public issues cannot be used for account or billing matters.
