# 行为准则

## 承诺

AnyTTY 致力于为所有参与者提供免受骚扰的社区环境，不因年龄、身体状况、残障、族裔、性别身份与表达、经验、教育、社会经济状况、国籍、外貌、种族、宗教或性取向而区别对待。

## 期望行为

- 尊重他人，表达具体并保持建设性。
- 假定善意，同时为行为造成的影响负责。
- 接受纠正、聚焦技术问题并正确署名他人工作。
- 保护隐私数据、凭据和尚未公开的漏洞细节。
- 尊重维护者对范围、安全与发布成熟度的决定。

骚扰、威胁、歧视性语言、性意味关注、故意恐吓、持续干扰、公开他人隐私和人身攻击均不可接受。

行为问题请通过 GitHub 仓库联系渠道私下报告；只有产品漏洞才使用安全 advisory。维护者可编辑或删除内容、限制参与或封禁有害参与者。处理时会考虑上下文、影响与既往行为，并尽可能保密；直接涉事的维护者必须回避。

本政策改编自 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html)。
