# 支持

AnyTTY 是预发布软件。目前没有受支持版本、服务等级承诺、付费支持计划或保证响应时间。

- 设置、设计和使用问题可在仓库启用 Discussions 后使用 [GitHub Discussions](https://github.com/lozzo/anytty/discussions)。
- 可复现的公开源码缺陷使用 [Bug 表单](https://github.com/lozzo/anytty/issues/new?template=bug_report.yml)。
- 范围明确的改进建议使用 [Feature 表单](https://github.com/lozzo/anytty/issues/new?template=feature_request.yml)。
- 安全问题使用[私密漏洞报告](https://github.com/lozzo/anytty/security/advisories/new)，不要公开利用细节或凭据。

提交前请搜索已有 issue 并执行 `CONTRIBUTING.md` 中的检查。提供操作系统、提交版本、route 类型、准确命令、可复现步骤和脱敏日志；不要包含 claim、grant、密钥、终端内容、个人数据或生产服务标识。

AnyTTY Cloud 可用性、账号支持和商业条款与本源码仓库的社区支持分开，公开 issue 不处理账号或计费问题。
