# 商标政策

Apache-2.0 授予其覆盖源码的版权和专利许可，但不授予使用 AnyTTY 名称、图标、服务标识或近似品牌来暗示官方认可、官方身份或来源的权利。

可以使用 AnyTTY 名称客观描述兼容性、未修改源码、fork、评测或社区讨论；上下文必须清楚区分官方内容与第三方内容。

修改版发行物和托管服务未经书面许可不得自称官方 AnyTTY 产品，也不得把 AnyTTY 品牌作为主要身份。它们应明确说明修改内容和运营者。不得以容易造成混淆的方式把 AnyTTY 标识用于域名、应用标识、公司名或服务名。

本政策不限制适用法律允许的指称性合理使用。发布带品牌材料前，可通过 GitHub 联系仓库所有者咨询许可。本译文仅用于理解；如有冲突，以根目录英文 `TRADEMARKS.md` 为准。
